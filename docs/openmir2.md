# 传奇 1.76 + 克制扩展：OpenMir2 单人养老服深度调研与实施计划 (v3.2 沉浸交互与独立扩展版)

> **版本定位：** 面向本地/私有环境的**单人长线养老工程**（v3.2 道具/NPC 沉浸交互 + 精英领主色彩生态 + `OpenMir2.SoloExtension` 解耦架构）
>
> **核心优先级：** **存档与运行稳定（零坏档风险） > 砍掉单人垃圾时间且保留 RPG 仪式感 > 1.76 经典慢节奏与打宝惊喜 > 渐进式后期扩展**
>
> **代码改造铁律：** 鉴于 `OpenMir2` 官方仓库已趋于稳定不再频繁大更，所有新增机制直接通过 C# 源码实现；但**严禁将新逻辑揉进老代码**，必须全部收拢在新建的 **`OpenMir2.SoloExtension`** 独立命名空间下，老代码仅保留极简的**单行调用（One-Line Hook）**，且扩展数据采用**旁路 JSON 独立存储**，绝不改动原生 `DBServer` 存档表结构。

## 二、 最终玩法范围：L0 经典 + L1 沉浸式减负 + L1.5 色彩精英领主 + L2 慢扩展

单人玩 1.76 最大的敌人不是怪物太强，而是**“大量的无意义垃圾时间”**（跑图 $15$ 分钟、弯腰捡满地药水、回城跑四家店逐个拖卖铁匠、道士法师下线丢宝宝、蹲守 $6$ 小时大 Boss）。同时，如果把所有功能都做成无交互的后台命令，又会丧失传奇经典的 RPG 沉浸感。因此我们确立如下四层架构：

```text
[L0: 1.76 原版基石] ──► [L1: 道具/NPC 媒介化减负] ──► [L1.5: 色彩预警精英与领主] ──► [L2: 1.80+ 渐进慢扩展]
 战法道三职业核心        行军帐(建营/返场)+回城卷       普通怪 -> [词条精英] -> [领主]   魔龙城 -> 雷炎洞穴 -> 火龙
 沃玛/祖玛/赤月/重装     军需官NPC(跨店统卖+一键特修)   249猩红领主/251金色富饶/惊扰度   按通关进度逐图解锁
 死亡不掉身上穿戴装      自动免Shift/范围拾取/猎魔手札  半血召亲卫/残血狂暴禁回血        属性缓坡过渡(15%~25%)
```

### 2.1 L0：必须先守住的 1.76 核心与死亡保护改造

* **三职业与地图闭环：** 战、法、道三职业核心技能手感 $100\%$ 还原；完整走通比奇 $\rightarrow$ 骷髅/僵尸洞 $\rightarrow$ 蜈蚣/猪洞 $\rightarrow$ 沃玛 $\rightarrow$ 祖玛 $\rightarrow$ 封魔 $\rightarrow$ 苍月 $\rightarrow$ 白日门/赤月 $\rightarrow$ 六大重装。
* **死亡惩罚改造（穿戴装备 $100\%$ 零掉落保护）：**
  * **痛点：** 单人养老辛苦几个月打出一把运 $7$ 裁决或圣战手镯，一旦在赤月卡顿死亡爆出且被刷新吞没，会导致玩家直接弃坑。
  * **规则：** 底层拦截人物死亡爆穿戴装逻辑，**身上穿戴的所有装备（武器、衣服、头盔、项链、手镯、戒指、靴子、腰带、勋章）死亡掉落率强制设为 $0\%$**。
  * **保留适度紧张感：** 死亡时**允许掉落背包（包袱）内的部分非绑定物品**（如散装药水、回城卷、刚打到还没存仓的普通战利品）。玩家复活后可通过城内的【玛法行军帐】快速传回洞穴营地“跑尸”捡回包袱散物，既有魂系/老传奇的刺激感，又绝不伤筋动骨。

## 三、 专项设计一：去垃圾时间与“道具/NPC 媒介化交互”体系 (L1)

> **设计哲学：** **保留后台 `@` 快捷指令作为调试与兜底**，但面向玩家日常游玩时，所有便利功能均通过**极具传奇古朴质感的“实体道具”与“行会/城镇 NPC”**来触发，让“打宝 $\rightarrow$ 回城 $\rightarrow$ 整备 $\rightarrow$ 返场”充满 RPG 仪式感。

### 3.1 核心循环：【回城卷】+【军需官 NPC】+【玛法行军帐】的 30 秒整备闭环

我们完全摒弃“野外地上白装直接变金币”或“原地凭空买卖”的快餐做法，打造最具烟火气的单人整备循环：

```text
[洞穴酣战] 4x4范围自动拾取战利品入包 ──► [背包满载] 双击经典【回城卷/地牢逃脱卷】回到盟重安全区
     ▲                                                                       │
     │                                                                       ▼
[满血返场] 双击包内【玛法行军帐】传回洞穴营地 ◄── [城镇整备] 点击安全区【军需整备官】(或任意铁匠/服装店)
                                                            一键跨店统卖普通装(自动锁死小极品) + 一键全身特修
```

### 3.2 四大核心交互媒介设计（道具与 NPC 替代纯命令）

#### 1. 营地锚点媒介：【玛法行军帐】（替代纯 `@camp` 无交互传送）
* **物品形态：** 在 `StdItems.DB` 中新增一件可永久重复使用的特殊道具 **【玛法行军帐】**（`StdMode = 31` 双击触发类物品，外观复用古朴卷轴或包裹图标，出生赠送或比奇杂货铺低价购买）。
* **交互逻辑与场景限制（极具沉浸感）：**
  * **在洞穴/野外双击【玛法行军帐】：** 弹出经典对话框，显示当前所在地图与坐标，点击 **`[在此处扎下营帐/@Camp_Set]`**，消耗 $1$ 个地牢逃脱卷（或 $1,000$ 金币物资费），在脚下记录唯一营地坐标（屏幕提示：*“你在石墓五层 (142, 88) 升起了篝火，扎下了行军营帐。”*）。
  * **在城镇安全区双击【玛法行军帐】：** 弹出对话框，显示已记录的营地位置（如 `祖玛五层 120:95`），点击 **`[整理行装，返回营地/@Camp_Return]`**，瞬间传回刚才扎营的洞穴深处。
  * **防作弊与保留回城卷价值（关键规则）：**
    1. **回城必须靠【回城卷 / 地牢逃脱卷】：** 行军帐**不提供**“从野外直接飞回安全区”的功能，从而完美保留经典传奇中打蝙蝠/蜜蜂爆回城卷、出门必带回城卷的生存法则。
    2. **野外禁止直接飞营地：** 只有身处**城镇安全区**（或已死亡复活后）才能点击“返回营地”，防止在洞穴里被怪包围时把行军帐当成无限瞬移逃生外挂。
    3. **终极 Boss 房禁扎营：** 顶层巢穴（如赤月魔穴、恶魔祭坛、祖玛教主之家、石墓七层）禁止扎营，只允许在上一层（如抉择之地、祖玛七层大厅、石墓六层）扎营，保留最后一段冲门挑战的刺激感。

#### 2. 售卖与特修媒介：【军需整备官 NPC】与传统商店改造（替代纯命令售卖/修理）
* **痛点：** 原版 1.76 回城卖垃圾极其折磨——武器要去铁匠铺、衣服要去布料店、戒指手镯要去首饰店，还要把物品一件件拖进出售框，且极易手滑把 $+3$ 极品死神手套卖给商店。
* **交互改造：**
  * **方式 A（专属 NPC）：** 在比奇与盟重安全区中心（仓库保管员旁）设立 **【玛法军需官】**。
  * **方式 B（改造现有商店 NPC）：** 在原有的铁匠铺（武器）、服装店（衣服）、首饰店 NPC 对话框底部，统一追加两个高亮选项（打破原版商店只能卖单一品类装备的限制）：
    * **`[【一键出售】清理包内普通战利品/@Solo_QuickSell]`**
    * **`[【全身特修】立即特修身上全套装备/@Solo_QuickRepair]`**
* **智能防误卖保护（由 `SoloExtension` C# 底层执行）：**
  * 当玩家点击 `[一键出售]` 时，`TownServiceModule` 自动遍历玩家背包，将设定的普通商店装（如轻盔、修罗、凝霜、蓝翡翠等）按商店标准价批量结算为金币，伴随清脆的金币入账音效。
  * **极品锁死铁律：** 只要某件装备带有 **$\ge +1$ 点极品附加属性**（如攻 $+1$ 青铜头盔、道 $+2$ 降妖除魔戒指）、或带有幸运属性、或属于沃玛及以上级别名牌装、或纯度 $\ge 15$ 的黑铁矿，系统**自动跳过绝不出售**，并在聊天栏绿字汇报：
    > *“【军需官】：已为您收购 16 件普通战利品，结算 38,500 金币！（已自动为您过滤保护包内 2 件极品属性装备）”*

#### 3. 随身设置与图鉴媒介：【玛法猎魔手札】（替代纯 `@autoloot` / `@boss` 命令）
* **物品形态：** 背包常驻轻量化特殊书籍 **【玛法猎魔手札】**（重量 $0$，死亡绝不掉落，双击打开古朴的 NPC 面板）。
* **面板交互功能：**
  1. **【战斗与拾取开关】：** 一键切换 **“$4 \times 4$ 范围自动拾取”**（全部拾取 / 仅拾取金币药水与极品名牌 / 关闭）与 **“自动免 Shift 持续挥砍”**。
  2. **【本图猎魔感知（原 `@boss`）】：** 点击“感知当前区域高危气息”，手札会以 RPG 叙事口吻提示本图生态：
     > *“手札微光闪烁：当前区域【惊扰度 72/100】；东北方向残留着【[领主]邪恶白野猪】的狂暴气息；殿堂首领【沃玛教主】预计将在 14 分钟后苏醒。”*
  3. **【玛法怪物图鉴】：** 查看当前已解锁的怪物击杀进度与永久属性加成（如：*“白野猪图鉴已圆满：人物永久防御 $+1$，对猪系怪物伤害 $+5\%$”*）。

#### 4. 宠物托管媒介：【比奇/盟重驯兽师 NPC】
* 法师在野外诱惑的 $5$ 只宝宝（如 $7$ 级巨型多角虫、半兽勇士、虎卫），下线时由 `SoloExtension` 自动序列化保存至旁路 JSON；下次上线后，法师只需走到安全区点击 **【皇家驯兽师】** 选择 **`[领回寄养的契约魔宠]`**，即可瞬间召回下线前的 $5$ 只满级宝宝，彻底告别每次上线先花 $40$ 分钟招怪练级的苦役。

> **注：保留 `@` 命令兜底对照表**
> 为了方便您在开发调试或习惯键盘流操作时快速调用，`SoloExtension` 依然保留以下后台指令（与道具/NPC 调同一套 C# 方法）：
> `@camp`（打开行军帐面板）、`@sell`（触发军需官一键售卖）、`@repair`（触发全身特修）、`@autoloot`（切换范围自动拾取）、`@boss`（查看本图惊扰度与领主感知）。

## 四、 专项设计二：Crystal 风格“动态精英与区域领主”色彩预警体系 (L1.5)

为了解决传统 1.76 单机刷小怪平淡无奇、大 Boss 刷新等待太久的痛点，我们在不改动客户端素材（零补丁负担）的前提下，引入**“地图惊扰度（Map Heat）”**与**“名称色彩视觉预警”**体系。

### 4.1 四级怪物生态与名称色彩视觉规范（基于传奇 256 标准色板）

当玩家在洞穴中刷怪时，一眼就能通过怪物名字的颜色分辨出“普通怪、致富怪、高攻怪与高危领主”：

| **T3 殿堂大 Boss** | `祖玛教主`、`赤月恶魔` | **`253` (深邃紫红色)** | 传奇终极首领压迫感 | 1.76 单人微调值 | 赤月终极套、六大重装、特戒材料、必掉保底气运积分 |

### 4.2 “地图惊扰度（Map Heat）”主动涌现机制

单人刷图不再纯看脸枯燥干刷，而是拥有清晰的节奏感：
1. **累积惊扰度：** 玩家在任意洞穴每击杀 $1$ 只普通怪，当前地图的 `MapHeat` 增加 $3 \sim 4$ 点。
2. **触发精英（$\ge 50$ 点）：** 当惊扰度突破 $50$ 点时，下一次击杀普通怪将有极高概率在身边直接变异刷出一只带对应色彩的 **T1 词条精英怪**（如 **`251` 金色 `[富饶]`** 或 **`250` 橙色 `[狂暴]`**）。
3. **惊动区域领主（满 $100$ 点）：** 当惊扰度达到 $100$ 点（约清理 $30$ 只怪，耗时 $5 \sim 8$ 分钟），系统清零惊扰度，屏幕顶部弹出猩红色警报：
   > *“【洞穴异动】你的持续杀戮惊动了盘踞在本层的霸主——【[领主]血煞白野猪】在附近现身了！”*
   随即在玩家视野边缘刷出一只 **`249` 猩红色名字**的 T2 区域领主！

### 4.3 区域领主（Lord）与大 Boss 的两段式单人友好 AI

1. **阶段一（$50\%$ 血量 —— 亲卫响应）：** 领主血量首次降至 $50\%$ 时发出怒吼，在身边召唤 $2 \sim 3$ 只同族护卫怪，破除无脑卡墙站撸，增加单人走位拉扯乐趣。
2. **阶段二（$20\%$ 血量 —— 困兽犹斗且禁绝回血）：** 领主血量降至 $20\%$ 时攻速提升 $20\%$，但**强制关闭其自然回血能力（`PerilRegenDisabled = true`）**。彻底解决 1.76 原版单人战士砍大 Boss 时“Boss 回血比砍得还快”的无解死局。

## 五、 技术架构规范：新建 `OpenMir2.SoloExtension` 命名空间与解耦设计

> **核心工程原则：**
> 1. 所有新增 C# 代码**100% 放入新建的 `OpenMir2.SoloExtension` 命名空间（独立文件夹）**，绝不把长篇逻辑塞进原有的 `PlayObject.cs` 或 `MonsterObject.cs` 中。
> 2. 原有老代码仅在关键生命周期处插入 **$1$ 行静态方法调用（One-Line Hook）**。
> 3. 所有扩展存档（营地坐标、猎魔手札开关、怪物图鉴、法师离线魔宠、Boss 保底气运）全部保存在独立的 **`Mir200\Envir\SoloData\Solo_{角色名}.json`** 中，**对原版 `DBServer` 数据库零侵入、零坏档风险**。

| 序号 | 原版源码文件与方法位置 | 仅需插入的单行调用代码 (`using OpenMir2.SoloExtension;`) | 实现的核心功能 |
| :--- | :--- | :--- | :--- |

| **2** | `PlayObject.cs` $\rightarrow$ `Run()` (人物主循环每 $500\text{ms}$) | `SoloExtensionHost.OnPlayerTick(this);` | 驱动 **$4 \times 4$ 范围自动拾取**与**免 Shift 持续普通攻击锁定** |

| **8** | `PlayObject.cs` $\rightarrow$ `MakeGhost()` (下线) / `RunNotice()` (上线) | `SoloExtensionHost.OnPlayerLogin(this);` / `OnPlayerLogout(this);` | 自动加载/保存 `Solo_{Name}.json` 旁路存档与法师契约魔宠数据 |

### 5.3 核心 C# 模块实现蓝图（`OpenMir2.SoloExtension`）

```csharp
namespace OpenMir2.SoloExtension
{
    public static class SoloColorPalette
    {
        public const byte NormalWhite  = 255; // 普通怪：纯白
        public const byte WealthyGold  = 251; // [富饶]精英：耀眼金色（突显财富）
        public const byte BerserkOrange= 250; // [狂暴]精英：烈焰橙色（突显高攻）
        public const byte SwiftCyan    = 254; // [迅捷]精英：电光青色（突显极速）
        public const byte ToughGreen   = 241; // [坚韧]精英：翠绿重甲（突显防御与黑铁矿）
        public const byte LordCrimson  = 249; // [领主]霸主：猩红危险色（突显高危与高回报）
    }

    public static class SoloExtensionHost
    {
        // Hook 1: 死亡不掉穿戴装备（保留包袱掉落）
        public static bool ShouldBlockUseItemDropOnDeath(PlayObject player)
        {
            // 直接拦截身上穿戴装备(UseItems)的死亡掉落，100%保护玩家心血装备
            player.SysMsg("【玛法庇护】你的穿戴装备受到了灵魂绑定保护，未曾遗落！", MsgColor.Green, MsgType.Hint);
            return true; 
        }

        // Hook 4: 双击【玛法行军帐】或【玛法猎魔手札】道具触发
        public static bool TryHandleCustomItemUse(PlayObject player, UserItem item)
        {
            var stdItem = SystemShare.ItemSystem.GetStdItem(item.Index);
            if (stdItem == null) return false;

            if (stdItem.Name == "玛法行军帐")
            {
                TownServiceModule.OpenCampDialog(player);
                return true; // 保持道具不消耗，弹出扎营/返场对话框
            }
            if (stdItem.Name == "玛法猎魔手札")
            {
                BestiaryModule.OpenHunterTomeDialog(player);
                return true;
            }
            return false;
        }
    }
}
```
