# 1. C# 引擎级动态掉落（已内置于 OpenMir2.SoloExtension.EcologyModule）：
#    - [富饶] 金名精英（色号 251）：必额外爆出 8,000 ~ 20,000 满地金币 + 1~2 件必带 +1~+3 极品属性的首饰
#    - [狂暴] 橙名精英（色号 250）：额外爆出 3,500 ~ 7,500 金币 + 极品首饰 + 强效太阳水
#    - [迅捷] 青名精英（色号 254）：额外爆出 2,500 ~ 5,000 金币 + 2 瓶高阶补给药水（强效太阳水/疗伤药）
#    - [坚韧] 绿名精英（色号 241）：必掉纯度 15 ~ 25 的高纯度黑铁矿石（解决单人升裁决/骨玉/龙纹缺高纯矿痛点）
#    - [领主] 猩红霸主（色号 249）：地图惊扰度满 100 必刷！必爆 18,000 ~ 36,000 金币 + 纯度 18~27 黑铁矿石 + 沃玛名牌/祝福油 + 10点首领保底气运
#    - [首领] 紫名教主（色号 253）：每次击杀累积 25 点猎魔保底气运，气运满 100 必额外爆出珍稀极品名牌！
#
